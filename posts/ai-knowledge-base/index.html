工具使用
#

CC Switch 安装
#

CC Switch 是一个跨平台桌面工具，用于统一管理 Claude Code、Codex、Gemini CLI、OpenCode、OpenClaw 等多种 AI 编程 CLI 工具。支持一键切换供应商、统一管理 MCP/Skills、内置 50+ 供应商预设。

前置环境：Node.js

# 使用 Homebrew 安装
brew install node

# 或使用 nvm（推荐）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts

安装 CC Switch（macOS）

# 添加 tap
brew tap farion1231/ccswitch

# 安装
brew install --cask cc-switch

# 升级
brew upgrade --cask cc-switch

功能特性：

  • 一个应用管理五个 CLI 工具
  • 50+ 供应商预设，一键切换
  • 统一 MCP/Skills 管理
  • 系统托盘快速切换
  • 支持云同步（Dropbox/OneDrive/iCloud/WebDAV）

Claude Code 安装
#

Claude Code 是一个由 AI 驱动的代理编码工具，可以读取你的代码库、编辑文件、运行命令，并与你的开发工具集成。它理解你的整个代码库，可以跨多个文件和工具工作以完成任务，帮助你构建功能、修复错误和自动化开发任务。

官方中文文档：https://code.claude.com/docs/zh-CN/overview#native-install-recommended

方式一：Homebrew（macOS 推荐）

brew install --cask claude-code

方式二：npm

npm install -g @anthropic-ai/claude-code

# 国内用户如下载慢，使用镜像源
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com

验证安装：

claude --version

启动 Claude Code：

cd your-project
claude

也可以通过 CC Switch 设置界面直接安装。

ClawGod - 解锁 Claude Code 全部权限
#

ClawGod 是一个开源工具，可以解锁 Claude Code 的更多功能权限。

项目地址：

  • GitHub：https://github.com/0Chencc/clawgod
  • 官网：https://clawgod.0chen.cc/

安装命令：

curl -fsSL https://raw.githubusercontent.com/0Chencc/clawgod/main/install.sh | sh

网络不通时，可下载 install.sh 文件，本地执行 sudo sh install.sh

启动命令：

claude

启动后显示绿色图标 = 已修复（补丁版本），橙色图标 = 原版。

MCP (Model Context Protocol)
#

MCP 是一种用于 AI 模型与外部工具交互的协议，可以让 Claude Code 与各种开发工具和数据源集成。

Claude Skills 管理
#

Skills 是 Claude Code 的扩展功能模块，可增强 AI 的专业能力。

Skills 仓库推荐：

  • Agent Skills Marketplace（推荐）：https://skillsmp.com/zh
    • 收录了大量实用的 Agent Skills，涵盖各行各业

安装 Skills 方式：

# 方式一：npx 命令安装
npx skills add 用户名/仓库名

# 方式二：通过 CC Switch 安装
# 下载 Skills.zip 压缩包
# 打开 CC Switch -> Skills -> 导入压缩包

示例：

npx skills add affaan-m/everything-claude-code
